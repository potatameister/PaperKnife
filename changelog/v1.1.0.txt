PaperKnife v1.1.0 (10100)

Efficiency:
- Fixed memory leaks: PDF pages and documents are now freed after use instead of piling up, preview cleans up when closed, download links are revoked properly
- Draft autosave capped (50MB, 24h) so it can't fill up storage; history logging fixed and capped; wipe/nuke now clears drafts too
- Zip and OCR code now loads only when you use those tools (startup ~110KB smaller)
- Fixed silent failures: tools now show an error message instead of hanging (incl. Signature)
- Removed debug error popup, working lint, synced versions

Issue #6 - history now works when tapped:
- Tap a history row for Open in its tool, Download, Share, Delete
- Results are saved with the history entry so they survive app restarts (25MB per entry cap, older entries show as expired)
- Sidebar redownload uses saved copy when the session link is dead

Privacy:
- No permissions declared in manifest (only invisible auto-granted Vibrate from haptics plugin)
- Android auto-backup disabled so app data stays on device
